The easiest way to deploy game servers on Windows. Free, open source, no account needed.

⬇ Download for WindowsAll releases

Installer (NSIS) and portable .exe · Windows 10/11 64-bit · builds are currently unsigned, so SmartScreen may warn you

Get running in four steps

Install

Run the installer, or unzip the portable build anywhere. Your data lives in %APPDATA%\NodeGSM.

Pick a game

Open Games → Add server, search the built-in plugins, read the defaults.

Install

One click downloads SteamCMD and the server with a live progress bar.

Start & automate

Start it, watch the console, then switch on auto restart, updates and backups.

Requirements

System

OSWindows 10 / 11 (64-bit)
DiskDepends on the game (Rust ~ 10 GB, ARK ~ 20 GB+)
NetworkPort forwarding / firewall rules for your game ports
AdminOnly for the firewall helper

Build from source

git clone 
cd Node.WGSM2026
npm install
npm start      # run
npm run dist   # installer + portable exe
