Convert a WindowsGSM plugin

Paste or upload the C# file of a WindowsGSM plugin and get a NodeGSM plugin.json, a README and a pull request description. The conversion runs in your browser: nothing is sent anywhere until you press Submit in the last option.

1. The C# plugin

Text only: the file is read as text, never compiled or run. Max 200 KB.

2. What was detected

a-z 0-9 _ - (2-32). Becomes the folder name plugins/<id>.
Relative to the server files folder, / separators.

      Details: the contributing guide. The pre-filled link puts the file text in the address (it only goes to github.com), which is why very long files fall back to copy and paste.
      
    
      

    
      
      
      
      
      
        
      The owners review your submission and, once approved, a draft pull request is opened for you in the Catalogue. You do not need a GitHub account. Only plugin.json and README.md are accepted, never code (plugin.js).
      
        
        
        An e-mail or a handle, only if the owners need to ask you something. Stored as plain text with your submission, visible to the owners only, never shown publicly. Leave empty to stay anonymous.
        
        
      What exactly is sent when I press Submit?
          
      The C# text you pasted (the server converts it again and checks the result; only its fingerprint is kept, not the C#), the id / name / author / executable shown above, your optional contact and the consent. Your IP address is only used as a hash for rate limits (3 per day, 1 per 10 minutes). Nothing is sent before you press the button.
