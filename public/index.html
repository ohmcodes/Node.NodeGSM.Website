Everything you need to run servers

Built for people who host games for friends, communities, or fun.

⚡

One-click install

SteamCMD downloads with live progress, strict success checks and first-run self-update.

🧩

Everything is a plugin

Games are plain folders with a plugin.json. Add or fix one with a pull request, no compiling.

🖥️

Live console & logs

Command input, multiple live-tailed log files per game, filters and error highlighting.

🛠️

Config editor

Edit INI, JSON, XML and more inside the app, with validation and automatic backups of the previous version.

🔁

Automation

Auto restart, auto start, auto update, cron restarts, backups and CPU priority or affinity.

🔔

Alerts & monitoring

Discord webhook alerts, player counts via A2S / UT3 / FiveM queries, system metrics in the header.
